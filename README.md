#Tech Community Platform

> A modern social platform for tech enthusiasts to share news, media, and ideas — built with Python and Flask.

---

#OVERVIEW

> This project is a tech-focused social networking platform where users can:

1. Share 📰 tech news

2. Post 🎥 videos and 🖼️ images

3. Interact via ❤️ likes and 💬 comments

4. Build a community around innovation and technology

---

✨ Features

1. User Authentication (Register, Login, Logout)

2. Create posts

3. ❤️ Like system

4. 💬 Comment system

5. 🖼️ Media support (images & videos)

6. 📊 Scalable backend structure using Flask

7. ⚡ Clean and responsive UI

---

🛠️ Tech Stack

1. Backend

1.1. Python 🐍

1.2. Flask

1.3. Flask-Login

1.4. Flask-WTF

1.5. Flask-SQLAlchemy

1.6. Flask-Migrate

2. Frontend

2.1. HTML

2.2. CSS

2.3. JavaScript

3. Database

3.1. SQLite (default)

⚙️ Installation

git clone https://github.com/Abbymsaru/community.git
cd community

python -m venv venv

# Activate virtual environment

venv\Scripts\activate # Windows
source venv/bin/activate # Mac/Linux

## pip install -r requirements.txt

---

▶️ Running the App

flask run
Open in browser:
http://127.0.0.1:5000
